## 更新纪律

1. **STATUS.md 单写者**：由协调者维护，不允许并行 agent 直接写。
2. **对照事实源**：状态判定以源码为准（`packages/*`），不以设计文档预期为准；设计与实现差异记入 STATUS 的「范围决策与剩余偏差」节（设计文档表述如与源码出入，以源码为准并同步修正设计文档）。
3. **实现变更必须回写**：任何源码改动落地后，若涉及模块状态/偏差清单，更新 STATUS.md 并追加更新日志行。
